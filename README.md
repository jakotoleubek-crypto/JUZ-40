# JUZ40 естелік альбомы

`index.html` файлын хостингке (мысалы, GitHub Pages, Netlify немесе Firebase Hosting) жариялауға болады.

## Баршаға ортақ сақтау

Әдепкіде альбом браузердің өзінде сақталады. Барлығы бір деректі көріп, өңдей алуы үшін:

1. [Firebase Console](https://console.firebase.google.com/) ішінде жоба және Web App ашыңыз.
2. Firestore Database және Storage қызметтерін қосыңыз; тест режимін тек қысқа мерзімге ғана қолданбаңыз.
3. `firebase-config.js` ішіндегі түсіндірме орнына Firebase Web App конфигурациясын жазыңыз.
4. Сайтты HTTPS хостингке жариялаңыз.

Firebase-те Firestore және Storage ережелері жарияланған сайттың доменінен оқуға/жазуға рұқсат етуі керек. Мектеп альбомы болғандықтан, жарияламас бұрын Firebase Authentication арқылы Google кіруін қосып, ережені тек сынып оқушыларына шектеу ұсынылады.

Бұл нұсқада әр адам тек өзіне берілген бет нөмірін өзгертуі тиіс. Қажет болса, келесі нұсқада әр бетке жеке құпиясөз не Google кіруін қосуға болады.
